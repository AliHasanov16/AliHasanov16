I build backend and business applications with C# and .NET, with a focus on clean, layered architecture.
Most of my hands-on experience comes from ERP integration work: moving real business data between Excel, custom APIs and the Logo Tiger database reliably and without manual entry.

- 9 months of software internship experience at BRM Yazılım

## What I Work On

- **ERP integration** — creating customer accounts, invoices, orders and warehouse stock records in Logo Tiger through application code
- **REST APIs** — JWT-secured ASP.NET Core Web APIs consumed by desktop and web clients
- **Real-time systems** — live dashboards and notifications with SignalR and Blazor Server

## Featured Projects

### [DevicePulse](https://github.com/AliHasanov16/DevicePulse)
Real-time device monitoring system. A lightweight agent running as a Windows Service streams CPU, RAM, disk usage and process changes to a central API over SignalR, and a Blazor Server dashboard displays every connected device live.
`.NET 8` `SignalR` `Blazor Server` `Worker Service` `JWT` `Clean Architecture`

### [Excel → Logo ERP Integration](https://github.com/AliHasanov16/Excel-Projesi)
Validates data from Excel files and imports it into Logo ERP, automatically creating customer accounts, invoices, orders and stock records. Built during my internship to replace manual data entry.
`C#` `WinForms` `Dapper` `SQL Server` `Logo ERP`

### [Stock & Lot Tracking API](https://github.com/AliHasanov16/ApiApplicationWinForms)
JWT-secured REST API with a desktop client for warehouse, variant and lot-based stock movements, connected to an ERP backend.
`ASP.NET Core Web API` `JWT` `HttpClient` `Dapper` `WinForms`

### [Smart Sales & Warehouse Console](https://github.com/AliHasanov16/AkilliSatisKonsolu)
Multi-warehouse management for Logo ERP: shelf-to-shelf stock transfers, FIFO deduction, unit conversions and invoice automation.
`C#` `Logo ERP` `Dapper` `SQL Server`

### [InternFlow](https://github.com/AliHasanov16/InternFlow)
Web-based project and task management portal with multi-role authorization and a live comment feed.
`ASP.NET Core MVC` `EF Core` `SignalR` `JWT` `SQL Server`
